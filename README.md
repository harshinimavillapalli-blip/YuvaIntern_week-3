# YuvaIntern_week-3
Performed statistical analysis and predictive modeling on the Pima Indians Diabetes dataset using R. Conducted hypothesis testing, correlation and normality analysis, data preprocessing, and Logistic Regression classification. Evaluated the model using cross-validation, confusion matrix, accuracy, precision, recall, F1-score, and ROC-AUC.

###  Dataset

**Dataset:** Pima Indians Diabetes Dataset
**Records:** 768
**Target Variable:** Diabetes outcome (`neg` / `pos`)
**Tools:** R, RStudio
**Libraries:** mlbench, tidyverse, caret, pROC

###  Tasks Performed

* Explored dataset structure and summary statistics
* Identified and handled missing values
* Performed descriptive statistical analysis
* Conducted hypothesis testing using t-tests
* Performed correlation analysis
* Checked normality and statistical assumptions
* Divided data into training and testing sets
* Built a Logistic Regression classification model
* Applied 10-fold cross-validation
* Generated a confusion matrix
* Evaluated accuracy, sensitivity, specificity, precision, F1-score, and ROC-AUC
* Performed model diagnostics and identified possible improvements

###  Model

**Logistic Regression** was selected because the target variable is binary and the model is suitable for classification problems.
